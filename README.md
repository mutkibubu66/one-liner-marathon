## The line

> My smartwatch congratulated me for standing up — the saddest applause I have ever received.

The setup is a small, everyday victory: a watch cheering you on for
standing up. The punchline reframes that cheer as applause — and then
undercuts it completely, because applause for standing up is the saddest
kind there is.

## How it works

`main.py` (pure Python 3.13 stdlib, no network) writes exactly that one
line, plus a trailing newline, to `/output/entry.txt`. The line is 91
characters, inside the 1–280 character gate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
